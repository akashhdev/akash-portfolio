Mandarin, made practicable

LangX

An AI-assisted Mandarin workspace that turns vocabulary, passages, audio, and grammar into focused practice for independent learners and classrooms.

Open LangX ↗
Problem

Language tools often split vocabulary, reading, listening, and grammar into disconnected experiences with little continuity.

Solution

One practice environment where generated material, saved vocabulary, notes, and progress can reinforce each other.

My contribution

Product direction, interface design, full-stack implementation, AI workflows, educator sharing, deployment, and ongoing operations.

Key capabilities

  • Flashcard decks and familiarity-based review
  • Generated reading with word-level glosses
  • Listening conversations and reports
  • Grammar exercises and comprehension questions
  • Educator publishing and classroom sharing
  • Saved progress and inline practice notes

A cinema at home

WatchX

A private media server for organizing and enjoying a personal film and series library across devices, without surrendering control of the collection.

Open WatchX ↗
Problem

A personal media library should remain organized, available, and pleasant to use without depending on an ever-changing set of streaming catalogs.

Solution

A customized Jellyfin server that indexes the collection and provides a consistent private viewing experience across devices.

My contribution

Server deployment, secure access, library organization, custom WatchX identity, operational maintenance, and the surrounding self-hosted stack.

Key capabilities

  • Personal film and series library
  • Cross-device browser playback
  • Metadata and collection organization
  • Private authenticated access
  • Custom WatchX presentation
  • Maintained self-hosted operations
